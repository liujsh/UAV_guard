# 无人机目标守卫仿真与分析软件

暂定名，计划发布版本 V1.0。

面向使用毕设实验环境的研究人员。用户在 Windows 桌面登录，创建项目，选择场景模板，配置不确定因素和随机种子，执行仿真，再从项目历史打开轨迹、指标和曲线。

## 模块与审核顺序

| 顺序 | 模块 | 验收 |
| --- | --- | --- |
| 1 | 场景配置 | 目标运动、障碍物、光照、行人、车辆和随机种子能校验、保存、读取 |
| 2 | 本地账户与项目 | 登录后建项目和打开项目，重启后能找回场景配置 |
| 3 | 桌面工作台 | 在项目内编辑场景与不确定因素，查看参数和校验反馈 |
| 4 | 仿真任务与离线后端 | 创建带参数快照的后台任务，记录运行状态、日志和时间序列 |
| 5 | AirSim 后端 | 在现有城市模板配置对象和环境，运行一次仿真并回收本次资源 |
| 6 | 结果与版本发布 | 回放轨迹、查看曲线、对照不同运行、导出 CSV 并验证 Windows 安装 |

每个模块通过自己的 PR 接受审核，后续模块基于合并后的版本开发。源文件按职责划分，公开接口记录单位和输入约定，版本化存储格式，记录第三方来源和实际功能。

## 当前可验证功能

场景配置使用 Python 标准库。使用 Python 3.12 运行测试。

```powershell
python -m unittest discover -s tests -v
```

`SceneConfig` 默认选择城市遮挡模板，目标沿模板路线正向以 0.7 m/s 行进。方向可切换为反向。行人和车辆可分别指定 0–4 个和 0–1 辆，预留给模板内已有的四组行人位与一个车辆位。障碍物使用相对于场景原点的北向、东向坐标，以米记录尺寸，可指定出现及消失时间。光照以无量纲有效增益表示。模块只负责参数及文件，场景资产和参数如何进入仿真由 AirSim 后端实现。
