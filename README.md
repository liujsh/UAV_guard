# 无人机目标守卫仿真与分析软件

暂定名，计划发布版本 V1.0。

面向使用毕设实验环境的研究人员。用户在 Windows 桌面登录，创建项目，选择场景模板，配置不确定因素和随机种子，执行仿真，再从项目历史打开轨迹、指标和曲线。

## 模块与审核顺序

| 顺序 | 模块 | 验收 |
| --- | --- | --- |
| 1 | 场景配置 | 目标运动、障碍物、光照、行人、车辆和随机种子能校验、保存、读取 |
| 2 | 本地账户与项目 | 登录后建项目和打开项目，重启后能找回场景配置 |
| 3 | 桌面工作台 | 在项目内编辑场景与不确定因素，查看参数和校验反馈 |
| 4 | 仿真任务与离线后端 | 创建带参数快照的后台任务，记录运行状态、日志和时间序列 |
| 5 | AirSim 后端 | 在现有城市模板配置对象和环境，运行一次仿真并回收本次资源 |
| 6 | 结果与版本发布 | 回放轨迹、查看曲线、对照不同运行、导出 CSV 并验证 Windows 安装 |

每个模块通过自己的 PR 接受审核，后续模块基于合并后的版本开发。源文件按职责划分，公开接口记录单位和输入约定，版本化存储格式，记录第三方来源和实际功能。

## 运行桌面工作台

在 Windows 上用独立的 Python 3.12 环境安装 Qt 依赖。以下命令使用 `uv` 创建环境，以避免使用 Conda 基础环境中已有的 Qt 库。

```powershell
uv venv --managed-python --python 3.12 .venv
uv pip install --python .venv/Scripts/python.exe -r requirements.txt
.venv/Scripts/python.exe -m guard_workbench.desktop
.venv/Scripts/python.exe -m unittest discover -s tests -v
```

启动后设置本地账号并创建项目。左侧选择项目，右侧填写场景、观测扰动并添加障碍物。中央是城市模板的俯视示意，滑块按配置预览目标位置和障碍物生效时间。用「保存场景」或 `Ctrl+S` 保存修改。工作区默认位于当前用户的本地应用数据目录，可使用 `--workspace` 指定另一个 SQLite 文件。

### 运行离线估计

点击视口下方的「运行」。如有场景修改，界面先验证并保存，然后生成独立的参数快照并启动后台任务。运行中可以继续浏览项目。任务结果、状态和起止时间保存在当前工作区，重启后可在项目下的运行历史中打开详情。程序意外终止时，未收到结束状态的记录显示「未完成」，可重新发起一个任务。

离线后端以 5 Hz 采样城市路线，按目标速度和方向生成真值，再用匀速卡尔曼滤波计算估计位置。光照增益按 `噪声标准差 / 光照增益` 作用于合成位置观测。遮挡为任务中段的指定时长。延迟取配置上限，观测在到达后的第一个采样时刻可用。结果保留每帧真值、估计位置、误差、95% 预测椭圆面积和本帧收到的观测采集时刻，同时统计全程 RMSE、覆盖率和样本数。障碍物几何、行人和车辆保留在场景快照中，供 AirSim 后端使用。

### 运行 AirSim 场景

1. 使用独立的 AirSim Blocks 1.8.1 实例运行桌面任务。把 [示例配置](examples/airsim_settings.json) 复制到模拟器主机，以 `-settings=<配置文件绝对路径>` 启动。Linux 渲染需有可用的显示会话，可配合 `-RenderOffscreen`。每个实例同时运行一个工作台任务。
2. 模拟器位于另一台机器时，从 Windows 建立 SSH 本地转发。例如 `ssh -N -L 127.0.0.1:41451:127.0.0.1:41451 <实验主机>`。
3. 在工作台的仿真任务选择「AirSim」，填写本地端口并点击「运行」。任务在 Blocks 中实例化目标、建筑、定时障碍物、行人与车辆盒体。完成后可从运行详情查看相机可见比例、距离均值和实际 RGB 末帧。

时序按 5 Hz 场景时钟记录。目标位置由 AirSim 回读，距离是相机到目标中心的三维距离，可见比例以实际分割帧中目标出现的样本数除以总样本数。行人与车辆按模板路线移动，属于脚本驱动的场景对象。亮度增益作用于位置观测门槛和合成噪声，观测还会应用设置的遮挡窗口和延迟。当前观测位置由真值加噪得到，飞行控制和论文中的守卫闭环属于独立实验。正常结束、取消或可恢复的错误会清理本任务创建的对象并恢复原暂停状态；连接失效导致清理无法确认时，任务详情会报告错误，下一次运行前应检查专用实例。

将 `GUARD_WORKBENCH_AIRSIM_TEST_PORT` 设为专用实例的本地端口后，运行测试会额外执行真实 AirSim 的定时障碍遮挡、取消和清理验证。

## 数据接口

`SceneConfig` 默认选择城市遮挡模板，目标沿模板路线正向以 0.7 m/s 行进。方向可切换为反向。行人和车辆可分别指定 0–4 个和 0–1 辆，预留给模板内已有的四组行人位与一个车辆位。障碍物使用相对于场景原点的北向、东向坐标，以米记录尺寸，可指定出现及消失时间。光照以无量纲有效增益表示。模块只负责参数及文件，场景资产和参数如何进入仿真由 AirSim 后端实现。

`Workspace` 在指定的 SQLite 文件中保存单个本地账号和多个项目。首次通过 `set_up_account` 设置用户名和密码，之后通过 `sign_in` 进入工作区。登录后可新建、列出、打开、重命名项目并保存其场景。重新启动应用后须登录，项目及场景从数据库加载。密码记录使用随机盐和 PBKDF2-SHA256 摘要。项目数据文件的访问权限由操作系统管理。
